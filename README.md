Skillwill Git & GitHub Exam Project
A practical exam project demonstrating Git version control, GitHub repository management, branching, merging, and merge conflict resolution.

Project Structure
index.html — Basic HTML5 page with a header and navigation menu.
README.md — Project documentation.

Stage 1 — Git & GitHub Basics
Initialized a local Git repository.
Created the initial project files.
Staged and committed changes.
Connected the local repository to GitHub.
Pushed the initial commit to the main branch.

Stage 2 — Branching & Merging
Created the feature-header branch.
Added a header section to index.html.
Committed and pushed the feature branch to GitHub.
Merged feature-header into main.

Stage 3 — Merge Conflict Resolution
Created two independent branches: nav-feature and nav-alt.
Added different navigation items in the same location of index.html.
Merged nav-feature into main.
Attempted to merge nav-alt, intentionally triggering a merge conflict.
Resolved the conflict by combining both navigation menus.
Completed the merge and pushed the final changes to GitHub.
